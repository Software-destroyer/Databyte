SLIDE 2: 1. INTRODUCTION & BACKGROUND
────────────────────────────────────────────────────────────────────────────────
• WHAT IS ON THE SLIDE:
  - Left: Bullet points contrasting signature-based NIDS (Snort, Suricata, Zeek)
    with ML-based anomaly detection (Decision Trees, Random Forest, SVM, XGBoost).
  - Right Top: Warning box highlighting the "Same-Dataset Evaluation Illusion."
  - Right Bottom: Visual flowchart comparing:
      * Same-Dataset Split (Train 80% / Test 20%)  --> 99% Accuracy [Illusion]
      * Cross-Dataset Transfer (Train A -> Test B) --> 40-60% Accuracy [Collapse]

WHAT WE ARE DOING WITH THE DATASETS HERE:
  - Explaining the core failure of single-dataset evaluation.
  - When models are trained and tested on the SAME dataset (e.g. only CICIDS2017),
    they cheat by learning testbed-specific artifacts (IP addresses, specific
    packet timings, background OS quirks).
  - When tested on an independent dataset (UNSW-NB15), these shortcut features
    disappear, causing detection accuracy to collapse.

SLIDE 3: 2. RESEARCH GAPS & MOTIVATION
────────────────────────────────────────────────────────────────────────────────
• WHAT IS ON THE SLIDE:
  - 3 Gap Cards:
      1. Gap I: Diagnosis Without Remediation (Verkerken 2022, Cantone 2024,
         Rosa 2022 observed the 25–42% collapse, but did not build a solution).

      3. Gap III: No Bidirectional Benchmarks (Studies test only A -> B, never

  - Bottom Diagram: Our end-to-end bidirectional solution pipeline connecting
    CICIDS2017 <---> Semantic Feature Alignment <---> 5 ML Models + CORAL <---> UNSW-NB15.

SLIDE 5: 4. METHODOLOGY — SYSTEM ARCHITECTURE PIPELINE
────────────────────────────────────────────────────────────────────────────────
• WHAT IS ON THE SLIDE:
  - 8-Step System Flowchart:
      Row 1: Step 1 (Ingestion & Cleaning) -> Step 2 (Semantic Mapping) ->
             Step 3 (Baseline Modeling) -> Step 4 (Cross-Dataset Transfer)
      Row 2: Step 5 (Divergence Analysis) <- Step 6 (Domain Transformation) <-
             Step 7 (Retrain & GRR Evaluation) <- Step 8 (Streamlit Dashboard)
  - Reference Boxes: Key Techniques (MI, RFE, Quantile, CORAL, Wasserstein, MMD)
    and Evaluation Metrics (Accuracy, Macro-F1, MCC, ROC-AUC, FAR, GRR).

EXACT ROLE OF THE 2 DATASETS ACROSS THE 8 STEPS:
  - Step 1: Clean raw CSVs of CICIDS2017 & UNSW-NB15 (fix Inf, NaN, drop constants).
  - Step 2: Map 80+ CICIDS features and 49 UNSW features into ~20 shared features.
  - Step 3: Train & test within CICIDS (99%) and within UNSW (98%) as baselines.
  - Step 4: Transfer: Train CICIDS -> Test UNSW; Train UNSW -> Test CICIDS (drops to ~50%).
  - Step 5: Compute Wasserstein & KL divergence to prove WHICH features drifted.
  - Step 6: Align the covariance matrices of the 2 datasets using CORAL.
  - Step 7: Retrain models on aligned features and calculate recovery percentage (GRR).
  - Step 8: Build the live web demonstrator.

SLIDE 8: 7. DOMAIN ALIGNMENT & MITIGATION STRATEGIES
────────────────────────────────────────────────────────────────────────────────
• 3 MITIGATION STRATEGY CARDS:
  1. Statistical Feature Selection:
     - Mutual Information (MI): Selects features predictive across BOTH datasets.
     - Recursive Feature Elimination (RFE): Prunes environment-specific features.
  2. Domain-Invariant Normalization:
     - Quantile Transformer & Robust Z-Score: Eradicates scale differences
       caused by UNSW's 10 Gbps network vs CICIDS's 1 Gbps network.
  3. CORAL (Correlation Alignment):
     - Unsupervised covariance matrix alignment:
       X_aligned = X_source * (C_source)^(-1/2) * (C_target)^(1/2)
     - Requires ZERO target labels! Completely unsupervised.
• 3 DIVERGENCE METRIC CARDS (Bottom):
  - KL Divergence: Measures relative entropy between feature distributions.
  - Wasserstein Distance: Earth Mover's Distance calculating manifold drift.
  - Maximum Mean Discrepancy (MMD): Kernel-based distance in Hilbert space.
